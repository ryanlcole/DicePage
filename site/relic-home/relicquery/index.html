ReLiC Query

Useful answers for Game Masters and players, written to stand on their own. ReLiC Query separates established guidance from opinion and separates RIST capability from RIST ambition.

Truth rule: ReLiC Query does not claim RIST solves a problem unless that capability is verified in the current product. Planned features are labeled planned. General tabletop advice remains system-neutral unless a ruleset is explicitly named.

LabelMeaning
