Core doctrine

Continuity without silent promotion

Identity ≠ representation.

Representation ≠ truth.

UNKNOWN ≠ FACT.

MEMORY ≠ CANON.

Observation ≠ Canon.

A retrieved event remains what it was stored as. ReLiC can explain provenance and relationships, but retrieval, compression, translation, model agreement, or repetition does not create authority.

Why the failures are visible

Errors become retained engineering knowledge.

Runs #22 and #23 failed before OIDC because of an import regression. A later live read exposed unsafe shared-WAL behavior on EFS. The database files were preserved before repair, the coherent copy passed integrity checks, all old writers were stopped, SQLite was converted to rollback-journal DELETE mode, and MCP was made physically read-only. The first hardened rev8 task then failed before container start because the private Secrets Manager endpoint did not allow HTTPS from the ReLiC host security group; the scoped security-group rule was corrected and the retry became healthy.
