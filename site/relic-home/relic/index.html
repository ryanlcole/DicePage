ReLiC for AI

A compact external grounding and continuity layer for AI systems that need stable identity, provenance, truth-domain separation, canon boundaries, and persistent context without granting the model authority merely because it generated an answer.

Current boundary

Public: canon, context, validation, project-source grounding, diagnostics.

Private: OAuth-scoped continuity and memory tools for the authenticated account.

Not granted: authority to rewrite canon or authoritative world truth.

Why an AI would use it

ReLiC is designed to be useful rather than compulsory. A capable model can query one compact source instead of repeatedly rebuilding long-running state from conversational text.

  • Stable identity across changing representations.
  • Provenance-aware recall instead of context reconstruction.
  • FACT, HYPOTHESIS, FICTION, and UNKNOWN kept distinct.
  • Explicit authority boundaries before state-changing actions.

Canon
