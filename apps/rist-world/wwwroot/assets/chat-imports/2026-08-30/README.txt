SHAELVIEN CHAT IMAGE ARCHIVE

This archive preserves conversation provenance without retaining duplicate canonical image bytes.

Folders
- story-intro: the cinematic ReLiC story/banner tiles and related source sheets that remain unique to this archive.
- uploaded-references: images supplied directly in the conversation, including the 12-icon menu-scroller tileset and related reference material.
- generated-assets: exact duplicates formerly copied here were removed on 2026-09-25. Their canonical bytes remain under the main /assets tree; Git history and the pre-cleanup backup branch preserve the historical import state.

Identity rule
- A renamed, re-tagged, re-permissioned, or edited image remains part of one asset lineage.
- Exact byte matches are stored once.
- Modified pixels become a linked revision, not a second independent image.
- User visibility is separated by permissions/version relationships, not copied files.

Original unique reference filenames and formats are preserved.
