RIST WORLD Privacy Notice

Last updated August 22, 2026.

Discord login

RIST WORLD uses Discord OAuth2 only to authenticate you. It requests the identify scope. It does not request your email, friends, servers, messages, presence, or permission to act on your behalf.

Data used

During login, the service reads your Discord account ID and display name. The account ID is immediately transformed into an internal RIST identifier and is not retained as Discord data. Your display name is retained only in a short-lived encrypted session record. Discord access tokens are not stored.

Private AWS storage

Your maps and assets are stored in a private, encrypted AWS S3 prefix assigned to the internal RIST identifier. The browser never receives AWS credentials and cannot choose another user's storage path.

Retention and deletion

Authentication sessions expire automatically. You may delete your private RIST storage and current session from the account controls while logged in. For access, correction, or deletion help, contact the application owner through the project's GitHub repository.

Sharing

Discord API data is not sold or used for advertising. AWS is used as the service provider for encrypted application storage.

RIST WORLD is not affiliated with or endorsed by Discord.
