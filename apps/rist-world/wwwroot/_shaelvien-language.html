Agent bootstrap

  1. Repository coding agents load .code-index/humans_language.json as the canonical machine-readable contract.
  2. Deployed tools discover that contract through /.well-known/shaelvien-language.json; the manifest carries the canonical path, version, and SHA-256.
  3. Use the repository sources named by that manifest when generating or modifying semantic code.
  4. Search existing CHIDs and Rune/Glyph/SHAEP units before inventing a new concept.
  5. Never infer identity from spelling, source line, target language, compact ASCII token, or UI representation.
  6. Preserve provenance, truth domain, authority scope, and error relationships.

Whatif explicitly enters hypothesis space. Maybe expresses UNKNOWN/uncertainty. Because attaches evidence, provenance, or rationale and does not itself prove causation.

Representation rules

  • Identity is not output equivalence.
  • Representation is not truth.
  • ASCII symbols, numeric opcodes, C#/JS/Python/SQL syntax, JSON keys, binary encodings, and visual controls are representations of semantic identities.
  • Text duplication does not automatically mean semantic duplication.
  • Equivalence must name its relation type and conditions.

Compact instruction streams

Forms such as i3r20 are currently illustrative, not canonical grammar. A production format must be versioned and unambiguous about opcode identity, operand type/length, target/symbol identity, block boundaries, registry/schema version, provenance, and authority context.

Decoder / perception compiler

incoming instruction/request
  -> framing + version check
  -> known Rune/Glyph?
  -> operand schema/type/range validation
  -> authentication + Recursive Authority/capability check
  -> CHID/SHAEP resolution
  -> resource/budget validation
  -> authoritative server state transition
  -> affected dependency delta
  -> browser perception/rendering

The browser is not authoritative world truth. It decodes approved semantic state into the representation appropriate for that client. Arbitrary eval or dynamic source execution is forbidden.

Provenance

Relevant semantic instructions, generated code, assets, and modifications preserve origin metadata: HUMAN, OUTSIDER_AI, or SHAELVIEN_EI. Unknown provenance defaults to the outsider/red boundary; editing AI-derived content does not erase its ancestry.

Error law

Errors become law. Recurring normalized failures should link to code IDs/CHIDs and, when known, Rune/Glyph semantics. A previously resolved failure that reappears is a regression and should be distinguished from an ordinary repeat.
