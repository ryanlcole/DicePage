Shaelvien Semantic Language

Developer / agent reference experimental language contract v0.1.0

Hidden reference: this page is intentionally absent from normal site navigation and requests no search indexing. It is a discovery/documentation surface, not an authentication or security boundary. No secrets belong here. The language may be public; authority determines what it is allowed to do.

Agent bootstrap

  1. Repository coding agents load .code-index/humans_language.json as the canonical machine-readable language contract.
  2. Load docs/SHAELVIEN_SEMANTIC_LANGUAGE.md for the current Rune/Glyph/SHAEP/CHID/CCTV, permission, perception, compact-stream, and pixel/property architecture reference.
  3. Deployed tools discover compatibility metadata through /Game/.well-known/shaelvien-language.json; the manifest carries the canonical contract path, version, and SHA-256.
  4. Search existing CHIDs and Rune/Glyph/SHAEP units before inventing a new concept.
  5. Never infer identity from spelling, source line, target language, compact ASCII token, numeric opcode, pixel, or UI representation.
  6. Preserve provenance, truth domain, authority scope, hidden-state boundaries, and error relationships.

Core identities

IdentityMeaning
CHIDPersistent semantic code identity independent of name, path, line, language, and UI representation.
RUNEAtomic semantic operation or intent.
GLYPHContextual or compound meaning composed from Runes and/or other Glyphs.
SHAEPSpatial Hot Preservation Object. Current authoritative format is SHAEP v2: stable ShaepId, preserved source/provenance, and a canonical hot archive representation.
CCTVTrusted context translation/verification boundary under development. Its long-form expansion is not yet canon and must not be invented by tooling.

Core rules

Server = authoritative truth

Truth domains

DomainRule
FACTAsserted true inside the declared real/system scope with evidence or provenance.
HYPOTHESISA possibility being explored; it cannot silently mutate FACT.
FICTIONInvented/world-canon truth inside its fictional scope without claiming real-world truth.
UNKNOWNUnresolved or insufficiently supported; not FALSE and not random chance.

Typed booleans

The semantic layer uses typed TRUE/FALSE, with epistemic UNKNOWN where a schema permits it. Numeric 0, 1, and -1 have no universal semantic truth meaning. A target or wire format may map a number to a boolean only when its schema explicitly declares that mapping.

Humans surface

If Then Whatif Maybe Maybeif Else Elseif Dont Because

Whatif explicitly enters hypothesis space. Maybe expresses UNKNOWN/uncertainty. Because attaches evidence, provenance, or rationale and does not itself prove causation.

Map / perception request

H52|C1|X23|Y42|Z74|T1|L9|I

This is a conceptual example, not frozen grammar: Human 52, Character 1, X=23, Y=42, Z=74, Tier=1, Layer=9, intent Inspect.

Hidden traps, reveal DCs/thresholds, GM notes, secret objects, and other unrevealed truth remain on the trusted side until the resolved context authorizes reveal. Hiding protected facts in DOM/CSS/browser memory is not security.

Pixel / property rule

pixel / screen position
 -> current representation node / hit target
 -> CHID or semantic UI identity
 -> permitted Rune/Glyph action

A pixel locates a representation at one moment; it is not the persistent identity of a Login button or another control. Responsive layout, localization, zoom, and accessibility may change the pixels while preserving the same semantic identity and action.

Compact instruction streams

Forms such as i3r20 are currently illustrative, not canonical grammar. A production format must be versioned and unambiguous about opcode identity, operand type/length, target/symbol identity, block boundaries, registry/schema version, provenance, and authority context.

Decoder / perception compiler

incoming instruction/request
 -> framing + version check
 -> known Rune/Glyph?
 -> operand schema/type/range validation
 -> authentication + Recursive Authority/capability check
 -> CHID/SHAEP resolution
 -> resource/budget validation
 -> authoritative server state transition
 -> affected dependency delta
 -> browser perception/rendering

The browser is not authoritative world truth. It decodes approved semantic state into the representation appropriate for that client. Arbitrary eval or dynamic source execution is forbidden.

Provenance and error law

Relevant semantic instructions, generated code, assets, and modifications preserve origin metadata: HUMAN, OUTSIDER_AI, or SHAELVIEN_EI. Errors become law: recurring normalized failures should link to code IDs/CHIDs and, when known, Rune/Glyph semantics; a regression is distinct from an ordinary repeat.
