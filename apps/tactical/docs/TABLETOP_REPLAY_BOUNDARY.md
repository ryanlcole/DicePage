# Tabletop Replay Boundary

Authoritative tabletop events may enter deterministic replay:

- card draw
- card reveal
- card share
- card use
- die roll
- coin flip
- Dice Bag resolution
- chip application
- initiative advance
- timer pause or resume when authoritative
- lore reveal

Excluded local UI events:

- overlay opening
- tray scrolling
- viewport pan
- viewport zoom
- viewport rotation
- personal tray placement
- decorative dice animation frames

The same authoritative tabletop event stream must reproduce the same card, dice, chip, initiative, and lore outcomes.
