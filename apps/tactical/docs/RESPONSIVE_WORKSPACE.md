# Responsive Workspace

Milestone: `SHAELVIEN-TACTICAL-WORKSPACE-1`

## Breakpoints

- Large desktop: `>= 1280px`
- Desktop/tablet landscape: `900px - 1279px`
- Tablet/large phone landscape: `600px - 899px`
- Phone portrait: `< 600px`

## Desktop

Desktop uses the full app shell:

- Docked app bar.
- Single-row main toolbar.
- Narrow tool rail.
- Bounded central map viewport.
- Docked right inspector with bounded resize handle.
- Bottom status bar.

## Mobile

Phone portrait uses:

- Compact app bar.
- One-row horizontally bounded tool strip.
- No permanent tool rail.
- Full-width map workspace.
- Bottom sheet inspector with collapsed, half, and full states.
- Safe-area padding.
- No page-level horizontal or vertical scrolling during normal editing.

The map is visible immediately on initial mobile load.
