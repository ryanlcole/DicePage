# Woodcut Tile Guide

Milestone: `SHAELVIEN-WOODCUT-TILESET-1`

Authoritative tile frame size: `32x32`.

Future HD redraw target: `64x64`, with the same silhouettes and registry IDs promoted only by Owner approval.

## Starter Sets

Implemented starter visual coverage:

- Temperate
- Forest
- Mountain
- Coast
- Snow
- Desert
- Swamp
- Village
- Town
- Tavern
- Dungeon
- Castle
- Ruins
- Magical terrain

## Terrain

Terrain defaults are image-backed through `data/tile_manifest.json`.

Autotile edge variants exist for:

- grass
- road
- water
- forest
- sand
- cliff
- snow
- stone

Autotiling is visual-only and must not change movement, triggers, visibility, encounter setup, replay, or rules.

## Objects

The first object set includes trees, bushes, flowers, logs, rocks, boulders, bridges, fences, signs, crates, barrels, chests, tables, chairs, shelves, beds, fireplaces, doors, windows, stairs, bar, torch, portal, and start/exit markers.
