# Shaelvien Visual Language

Milestone: `SHAELVIEN-WOODCUT-TILESET-1`

Shaelvien's map identity is a living carved artifact: a fantasy atlas burned into wood and made interactive through the tabletop engine.

## Exploration Maps

Exploration maps should look like historical map craft:

- Cities are carved symbols.
- Roads are engraved routes.
- Mountains are relief cuts.
- Forests are stylized woodland marks.
- Water uses carved flow lines.

## Tactical Interiors

Interior maps use the same wood-burned grammar with richer readable material cues:

- Tavern floors are wood planks.
- Walls and dungeon surfaces use stone hatching.
- Bar, tables, chairs, doors, and containers remain carved objects.
- Fire and magical elements use restrained presentation overlays only.

## Authority

This document defines visual direction only. It does not alter campaign canon, combat rules, map geometry authority, replay semantics, or first-preset campaign decisions.
