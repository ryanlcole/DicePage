# Workspace Design System

Milestone: `SHAELVIEN-TACTICAL-WORKSPACE-1`

The workspace uses CSS custom properties for a compact professional dark application style.

Primary token groups:

- `--app-bg`
- `--workspace-bg`
- `--panel-bg`
- `--panel-elevated`
- `--border-subtle`
- `--border-strong`
- `--text-primary`
- `--text-secondary`
- `--accent`
- `--accent-hover`
- `--danger`
- `--warning`
- `--success`

Controls use consistent heights, restrained borders, small radii, visible focus outlines, and compact type. The visual target is a finished productivity workspace while retaining Shaelvien's darker tabletop identity.

## Type Scale

- Product name: `15-16px`
- Toolbar labels: `12px`
- Inspector headings: `13-16px`
- Body fields: `12-14px`
- Status bar: `10.5-11px`

Large decorative headings are intentionally excluded from the editing workspace.
