# Lore Card Sharing

The Ancient Scroll toggles the active tabletop tray between gameplay cards and lore cards.

Lore cards support:

- title
- image reference
- contextual text
- source
- audience
- scene
- tags
- discovery state
- share state

The GM can share a lore card to the scene or selected audience. Player projections include only authorized shared cards and player-owned cards.

The full lore registry is not exposed by player projection. Static hosting cannot provide server-side secrecy by itself, so future shared packages must publish player-safe projections rather than GM source packages.
