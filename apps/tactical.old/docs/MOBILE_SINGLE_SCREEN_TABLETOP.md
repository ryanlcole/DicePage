# Mobile Single-Screen Tabletop

The mobile layout keeps the map immediately visible and prevents normal browser-page scrolling during play.

## Layout

- App bar and toolbar stay compact.
- The map remains centered.
- Edge trays collapse to compact physical objects.
- Major menus open as centered overlays with internal scrolling.
- The inspector and deck details use overlay behavior rather than permanent stacked panels.

## Input

- One-finger swipe pans.
- Pinch zooms.
- Two-finger twist rotates and snaps to cardinal angles.
- Tap selects.
- Double tap enters a child map.
- Long press opens a contextual menu.

Targeted CSS disables callout and accidental text selection inside the tabletop while preserving normal text behavior in fields and documentation.
