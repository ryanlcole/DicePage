# RuneCore elemental language × Old ReLiC (legacy continuity adapter)

**Owner correction, 2026-11-20.** Rion=binary, Ring=atomic ring, Rune=element, Glyph=periodic-table element identity, Shaep=what interacting Runes form, Repeat=cyclic recurrence. Older notes naming a rotating ring “Rune” or naming a rotation signature “Glyph” are superseded, not erased from Git history.

The separate legacy ReLiC project uses **AuthorityRune** for a sourced, authority-bearing record. An AuthorityRune is NOT a rotating Ring or an elemental Rune.

Legacy lifecycle: REMEMBER → EXIST → LIVE → IMAGINE → CREATE → SHARE → REMEMBER.

The additive old_relic_bridge.py here is only an isolated experiment ledger with occurred_at, recorded_at, hash chain, WORLD_SEED, CHECKPOINT and read-only viewport filtering. Its receipts are NOT receipts from the dedicated ReLiC host writer and never promote a Rune, Glyph or Shaep to scientific truth.

Generic ring_contacts.py performs proposed exact-matching tests on rotating zero positions without using element names. shaeps_from_links groups inferred candidate contacts into bounded Shaeps. It does not demonstrate chemical bonding or infer unknown periodic element ring structures.

Run from this folder: python -m unittest -v test_runecore_language test_old_relic_bridge test_corrected_terms .

The original legacy ReLiC repository, authoritative project database and the existing Shaelvien app are not modified by this experiment.
